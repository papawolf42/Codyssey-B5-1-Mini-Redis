# 0030 · ^= 이게 뭐야? 2^3 이 watch에서 8이될줄알았는데 1로나오는데?

## Q. ^= 이게 뭐야? 2^3 이 watch에서 8이될줄알았는데 1로나오는데?

---

파이썬에서 `^`는 거듭제곱이 아니라 **비트 단위 XOR(배타적 논리합) 연산자**입니다! *(거듭제곱은 `**` — 즉 `2 ** 3 == 8`입니다.)*

---

### 1. 왜 `2 ^ 3`이 `1`이 나왔을까?
XOR(`^`)은 두 수를 **2진수로 바꾼 뒤, 같은 자릿수끼리 비교해서 "서로 다르면 `1`, 같으면 `0`"**을 내는 연산입니다.

```text
  2  =  1 0  (2진수)
^ 3  =  1 1  (2진수)
-----------
결과 =  0 1  (2진수)  → 10진수로 1
```
* 왼쪽 자리: `1`과 `1` (같음 → `0`)
* 오른쪽 자리: `0`과 `1` (다름 → `1`)
그래서 `2 ^ 3 == 1`이 됩니다!

---

### 2. 그럼 `h ^= byte`는 무슨 뜻일까?
`h = h ^ byte`의 줄임말입니다. (`a += 1`과 같은 형태)

* 현재 32비트 해시값 `h`의 맨 아래 8비트와, 새로 들어온 문자 1바이트(`byte`)를 **비트별로 XOR해서 섞어주는 역할**을 합니다.
* 예를 들어 `"a"`(`97` = `0110_0001`)가 들어오면:
  ```text
  시작 h 하위 8비트 : 1100_0101  (0x...c5)
  ^ "a" (97)       : 0110_0001
  -----------------------------
  h ^= byte 결과   : 1010_0100  (0x...a4)
  ```
* 이렇게 아래 8비트가 바뀐 상태에서 바로 다음 줄의 `_FNV_PRIME` 곱셈을 하면, 그 바뀐 비트가 올림수(carry)를 타고 왼쪽 32비트 전체로 퍼져 나갑니다.

Watch 창에 `f"{(h ^ byte):032_b}"`를 같이 띄워보시면 방금 말씀드린 아래 8비트가 뒤집히는 모습이 그대로 보일 겁니다!
