# 0052 · `_heapify_down`의 `while True` 루프 한 줄씩 따라가기

## Q. `_heapify_down(0)`의 `while True:` 아래 코드를 `[9, 3, 2, 4, 5, 6]` 예제로 한 줄씩 따라가며 이해할 수 있을까요?

---

### 1. 먼저 짚고 갈 핵심 포인트 2가지

- **`index`, `left`, `right`, `smaller_child`는 “값이 아니라 칸 번호(인덱스)”예요!**  
  예를 들어 `smaller_child = 2`라면 값이 2라는 뜻이 아니라 **“2번 칸이 더 작은 자식이야”**라는 방 번호입니다.
- **`right < size and self._items[right] < self._items[left]` (단락 평가):**  
  파이썬 `and`는 **왼쪽(`right < size`)이 거짓이면 오른쪽을 아예 읽지 않습니다!** 그래서 오른쪽 자식이 없는 끄트머리에서도 `IndexError`가 안 나고 안전하게 넘어갑니다.

---

### 2. 한 바퀴씩 따라가 보기 (`size = 6`, 시작 배열 `[9, 3, 2, 4, 5, 6]`)

```text
시작 상태:        [9, 3, 2, 4, 5, 6]   (index = 0, 값 9를 내려보내는 중)

       9 [0]
      /     \
   3 [1]    2 [2]
   /  \     /
 4[3] 5[4] 6[5]
```

#### ① 1바퀴 (`index = 0`, 현재 값 `9`)
| 코드 | 하는 일 (쉬운 풀이) | 결과 |
|---|---|---|
| `left = 2 * index + 1` | 왼쪽 자식 방 번호 계산 (`2 * 0 + 1`) | `left = 1` (값 `3`) |
| `if left >= size:` | `1 >= 6`? 거짓 → 아직 자식이 있음! | 통과 |
| `right = left + 1` | 오른쪽 자식 방 번호 계산 | `right = 2` (값 `2`) |
| `smaller_child = left` | 일단 왼쪽(`1번 칸`)을 후보로 찜 | `smaller_child = 1` |
| `if right < size and self._items[right] < self._items[left]:` | `2 < 6`(있음!)이고 `2 < 3`(오른쪽이 더 작음!) | 참! |
| `smaller_child = right` | 더 작은 오른쪽(`2번 칸`)으로 후보 교체 | `smaller_child = 2` |
| `if self._items[index] <= self._items[smaller_child]:` | 부모 `9 <= 2`? 거짓! 아직 더 내려가야 함 | 교환 진행 |
| 자리 바꾸기 & `index = smaller_child` | `0번(9)` ↔ `2번(2)` 교환 후 `index = 2`로 이동 | 배열: **`[2, 3, 9, 4, 5, 6]`** |

#### ② 2바퀴 (`index = 2`, 현재 값 `9`)
- `left = 2 * 2 + 1 = 5` (값 `6`), `5 >= 6` 거짓 → 계속 진행
- `right = 6` → `right < size`(`6 < 6`)가 **거짓**이므로 오른쪽 자식은 아예 읽지도 않고 넘어감 (`smaller_child = 5` 유지)
- `9 <= 6`? 거짓 → `2번(9)` ↔ `5번(6)` 교환! `index = 5`
- 배열: **`[2, 3, 6, 4, 5, 9]`**

#### ③ 3바퀴 (`index = 5`, 현재 값 `9`)
- `left = 2 * 5 + 1 = 11`
- `if left >= size:` → `11 >= 6` **참!** (이제 아래에 자식이 아예 없는 바닥!)
- **`return`으로 함수 종료!** 바깥의 `pop()`은 처음에 챙겨둔 `1`을 돌려주고, 0번 칸에는 새 최솟값 `2`가 예쁘게 남아 있게 됩니다.
