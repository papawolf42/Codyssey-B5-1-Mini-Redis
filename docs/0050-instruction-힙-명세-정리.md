# 0050 · `instruction.md`의 최소 힙(Min Heap) 관련 명세 정리

## Q. `instruction.md`에 힙(Heap)과 관련된 요구사항이 어디에 어떻게 적혀 있나요?

---

### 1. 한눈에 보는 요약

`instruction.md`에서 최소 힙의 핵심 역할은 **“유통기한(`expire_at`)이 가장 빨리 끝나는 키를 맨 꼭대기에 올려두고 빠르게 찾아내는 알람시계”**입니다.

---

### 2. 명세 위치별 요구사항 표

| 명세 위치 | 요구사항 요약 | 쉬운 풀이 |
|---|---|---|
| **4-1. 기본 자료구조** | `push`, `pop`, `peek`, `size`와 `_heapify_up`, `_heapify_down` 직접 구현 / `(expire_at, key)` 형태 저장 | 파이썬 `import heapq`를 쓰지 말고, `(만료 시각, 키)` 쌍을 비교하는 최소 힙을 직접 만듭니다. |
| **4-2. 문자열 명령어** | 키 기반 명령 실행 전 **만료 여부 먼저 확인** / `DEL` 시 TTL 구조에서도 함께 정리 | 명령을 실행하기 전에 힙 꼭대기를 봐서 이미 만료된 키는 미리 지워야 없는 키처럼 처리됩니다. |
| **4-4. TTL 관리** | `EXPIRE`로 만료 시각 등록, `TTL`로 남은 초 조회 (없는 키 `-2`, 만료 없음 `-1`) / 지연 삭제(lazy deletion) 등 구현 선택 | `DEL`이나 `SET` 덮어쓰기 때 힙 중간을 억지로 뒤져 지우지 않고, 나중에 힙에서 꺼낼 때 낡은 기록을 버리는 방식도 허용합니다. |
| **7. 제약 사항** | 독립된 모듈 파일(`mini_redis/min_heap.py`)로 분리 + 핵심 클래스/함수에 주석 또는 docstring 작성 | 다른 자료구조 파일과 섞지 않고 따로 파일로 분리합니다. |
| **5. 보너스 1 (선택)** | 힙 내부 저장소까지 직접 만든 동적 배열로 바꾸는 것은 선택 과제 | 필수 과제에서는 파이썬 `list`를 그릇으로 쓰고, 힙의 정렬/비교 로직을 직접 구현합니다. |

---

### 3. 단계 연결

- **3-b (완료):** `push`, `peek`, `size`, `_heapify_up` — 넣기와 맨 위 확인
- **3-c (다음):** `pop`, `_heapify_down` — 맨 위 꺼내기와 순서 복구
- **6일차 (TTL):** `EXPIRE`, `TTL` 명령에 최소 힙을 연결해 실제 만료 처리 완성
