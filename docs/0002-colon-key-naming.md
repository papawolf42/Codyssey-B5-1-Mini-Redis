# 0002 · Redis에서 user:2 표기의 의미 (문법 vs 관습)

## Q. HashMap에서 user:2 로 표기한 건 이게 Redis 문법이라 그런가요?

**결론: 문법이 아니라, 실무에서 쓰는 “이름 짓기 관습(약속)”입니다.**

---

### 1. 왜 콜론(:)을 붙여서 쓸까요?

Redis는 관계형 데이터베이스(RDB)처럼 테이블이나 폴더가 따로 없고, 모든 데이터를 한 공간에 키-값(Key-Value) 형태로 저장합니다.

만약 키 이름을 그냥 `1`, `2`, `3` 또는 `apple`, `banana`처럼 지으면:
- `1`이 회원 번호 1번인지, 게시글 1번인지, 주문 번호 1번인지 구분이 안 됩니다.

그래서 개발자들은 보통 아래처럼 **콜론(`:`)으로 계층/카테고리를 나누어 표기**합니다:
- `user:1` → 회원 테이블의 1번 데이터
- `post:42` → 게시글 테이블의 42번 데이터
- `order:1001:items` → 1001번 주문의 품목 목록

---

### 2. 컴퓨터 눈에는 어떻게 보이나요?

파이썬 코드나 Redis 엔진 입장에서는 콜론에 특별한 기능이 전혀 없습니다.
`"user:2"`나 `"user_2"`나 `"철수"`나 똑같은 **일반 문자열(String)**로 취급됩니다.
즉, 문법적 제약이 아니라 사람이 읽고 구분하기 편하게 만든 표기법입니다.
