# 0027 · 이거 앞선 구현 테스트를 내가 돌려보려는데 debugging을 할건데 혹시 watch에서 

## Q. 이거 앞선 구현 테스트를 내가 돌려보려는데 debugging을 할건데 혹시 watch에서 2진법으로 볼수있는 방법있나?

---

네! 디버거의 **Watch(조사식)** 창은 **파이썬 표현식(코드)을 그대로 평가해서 보여주기 때문에**, 아래와 같이 포맷 문자열이나 `bin()`을 등록하면 바로 2진법으로 볼 수 있습니다.

---

### 1. Watch 창에 그대로 입력하면 되는 표현식

* **가장 깔끔한 방법 (32비트 0 채움 + 4비트마다 `_` 구분):**
  ```python
  f"{h:032_b}"
  ```
  예: `'1000_0001_0001_1100_1001_1101_1100_0101'`

* **간단히 보려면:**
  ```python
  bin(h)
  ```
  예: `'0b10000001000111001001110111000101'` *(앞쪽 `0`은 생략됨)*

* **현재 바이트(`byte`) 8비트 고정으로 보기:**
  ```python
  f"{byte:08b}"
  ```

*(참고: C/C++ 디버거처럼 변수 뒤에 `,b`를 붙이는 포맷 지정자는 VS Code 파이썬 디버거(`debugpy`)에서 기본적으로 2진법으로 먹히지 않으므로, 위처럼 파이썬 f-string이나 `bin()`을 쓰는 게 가장 확실합니다.)*

---

### 2. `fnv1a_32` 디버깅할 때 같이 걸어두면 좋은 Watch 4개
[hash_map.py](file:///C:/Users/alsgu/Dev/Codyssey/B5-1/mini_redis/hash_map.py#L14-L19)의 `for byte in ...` 안쪽에 브레이크포인트를 걸고 아래 4개를 Watch에 넣어두면 **XOR → 소수 곱셈 → 32비트 마스킹** 과정이 실시간으로 보입니다:

1. `f"{h:032_b}"` — 현재 `h` (32비트)
2. `f"{byte:08b}"` — 이번에 들어온 문자 1바이트 (8비트)
3. `f"{(h * _FNV_PRIME):_b}"` — 곱셈 직후 (32비트 넘게 길어지는 모습!)
4. `f"{((h * _FNV_PRIME) & _MASK_32):032_b}"` — `& _MASK_32` 후 아래 32비트만 남는 모습
