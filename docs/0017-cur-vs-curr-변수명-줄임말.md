# 0017 · 변수명에서 cur vs curr 줄임말과 3글자 대칭 스타일

## Q. 그럼 애초에 curr도 nxt처럼 3글자(cur)로 맞추면 안 되나?

---

### 결론
전혀 문제없고, 오히려 **3글자 대칭(`cur` / `nxt`)**으로 통일해서 쓰는 개발자도 아주 많습니다!

---

### 1. 실무에서 나뉘는 두 가지 네이밍 스타일

1. **`cur` / `nxt` 스타일 (3글자 대칭형):**
   - 현재 노드를 `cur`, 다음 노드를 `nxt`로 3글자씩 딱 맞춰서 시각적으로 깔끔하게 통일하는 스타일입니다.
   - 코드 가독성이 좋아서 알고리즘 풀이나 자료구조 구현에서 널리 쓰입니다.

2. **`curr` / `nxt` 스타일 (관습적 혼합형):**
   - 전통적으로 영어 `current`의 표준 약칭은 `curr`(4글자)입니다.
   - 원래는 `curr`와 `next`로 4글자 짝을 맞추고 싶었지만, 파이썬 내장 함수 `next()`와 이름이 겹치다 보니 어쩔 수 없이 `next`만 한 글자 줄여 `nxt`로 피한 경우입니다.
   - `prev`(4글자)와 글자 수를 맞추려고 `curr`를 고수하기도 합니다.

---

### 2. 코드 동작 관점
`__iter__` 등의 메서드 내부에서 쓰는 변수는 **지역 변수(Local Variable)**이므로, `cur`로 쓰든 `curr`로 쓰든 외부 동작이나 테스트 통과에는 전혀 영향이 없습니다. 개발자 취향이나 프로젝트 팀 컨벤션에 따라 3글자(`cur` / `nxt`)로 통일해도 아주 좋은 선택입니다.
