# 0034 · h의 32개비트중 아래 8비트를 쓴다는건 어디 코드야?

## Q. h의 32개비트중 아래 8비트를 쓴다는건 어디 코드야?

---

코드에 `"아래 8비트만 골라내라"`고 따로 적힌 줄은 없습니다! 바로 **`h ^= byte` 한 줄이 자동으로 그렇게 동작**하는 것입니다.

[hash_map.py](file:///C:/Users/alsgu/Dev/Codyssey/B5-1/mini_redis/hash_map.py#L16-L19)를 보면:
```python
for byte in key.encode("utf-8"):
    h ^= byte
```

이유는 **`byte`가 원래 8비트짜리 숫자(`0`~`255`)이기 때문**입니다.

1. `h`는 **32비트** 숫자이고, `byte`는 **8비트** 숫자입니다.
2. 자릿수가 다른 두 숫자를 `^`(XOR)하면, 오른쪽 끝자리를 기준으로 줄을 맞추고 **`byte`의 비어 있는 앞쪽 24칸은 전부 `0`으로 채워서** 계산합니다:
   ```text
   h    : [ 앞 24칸 (원래 숫자) ] [ 끝 8칸: 1100 0101 ]
   byte : [ 앞 24칸 (전부 0)    ] [ 끝 8칸: 0110 0001 ]
   ```
3. XOR에서 **`0`과 계산하면 원래 숫자가 1도 안 바뀌고 그대로** 나옵니다 (`0^0=0`, `1^0=1`).
4. 그래서 별도 코드가 없어도 **`h ^= byte`를 실행하면 앞 24칸은 그대로 남고 아래 8칸만 `byte`랑 섞이게 되는 것**입니다!
