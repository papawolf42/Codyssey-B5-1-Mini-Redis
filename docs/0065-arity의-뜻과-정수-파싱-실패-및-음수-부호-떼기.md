# 0065 · `arity`의 뜻과 정수 파싱 실패, 그리고 음수 부호 떼기 해석

## Q. ① `arity` 뜻과 정수 파싱 실패가 무엇을 의미하나요? ② `digits = text[1:] if text.startswith("-") else text`는 무슨 뜻인가요?

---

### 1. `arity` = “명령어 뒤에 와야 하는 인자 개수”

프로그래밍에서 함수나 명령이 받아야 하는 입력값(인자)이 몇 개인지를 가리키는 전문 용어입니다.
- `SET user:1 Alice` → 뒤에 2개 (`arity = 2`)
- `GET user:1` → 뒤에 1개 (`arity = 1`)
- `DBSIZE` → 뒤에 0개 (`arity = 0`)

*(낯선 용어라 코드에서는 더 직관적인 이름 `_ARG_COUNTS`, `_arg_count_of`로 바꾸었습니다.)*

---

### 2. “정수 파싱 실패”란?

터미널 입력창에 사용자가 치는 것은 처음에 **전부 글자(문자열)**입니다.  
예를 들어 `EXPIRE user:2 3`을 치면 `"3"`이라는 글자가 들어오는데, 이걸 계산 가능한 진짜 숫자 `3`으로 바꾸는 작업을 **정수 파싱**이라고 합니다.

숫자 자리에(`EXPIRE key 초`, `CONFIG SET maxmemory 숫자`) 숫자로 바꿀 수 없는 글자가 오면 파싱 실패로 보고 아래 에러를 냅니다:
```text
(error) ERR value is not an integer or out of range
```

| 입력 예시 | 결과 | 이유 |
|---|---|---|
| `EXPIRE a 10` | 성공 (`10`) | 정상 정수 |
| `EXPIRE a abc` | **실패** | 숫자가 아닌 글자 |
| `EXPIRE a 1.5` | **실패** | 소수는 정수가 아님 |
| `EXPIRE a 1_000` / `+5` | **실패** | 파이썬 `int()`는 받아주지만, 스펙상 순수 숫자만 허용하려고 걸러냄 |
| `CONFIG SET maxmemory -1` | **실패** | 메모리 한도는 0 이상이어야 함 |

> 💡 **검사 순서:** **인자 개수를 먼저** 보고, 개수가 맞을 때만 **정수인지** 검사합니다!  
> 예: `EXPIRE a`는 값이 하나 모자라므로 정수 에러가 아니라 **인자 개수 에러**가 먼저 납니다.

---

### 3. `digits = text[1:] if text.startswith("-") else text` 해석

한 줄로 쓴 조건식(**삼항 연산자**)으로, **“맨 앞에 `-` 부호가 붙어 있으면 `-`만 떼어 낸 나머지를 `digits`에 담고, 아니면 그대로 담아라”**는 뜻입니다!

풀어서 4줄로 쓰면 완전히 같은 코드입니다:
```python
if text.startswith("-"):
    digits = text[1:]   # 0번 글자("-")를 뺀 1번 글자부터 끝까지!
else:
    digits = text
```

| `text` | `digits` (검사용) | 뒤의 숫자 검사 결과 |
|---|---|---|
| `"30"` | `"30"` | 전부 숫자(0~9) → `int("30")` = `30` |
| `"-5"` | `"5"` | 전부 숫자(0~9) → 원래 `text`로 `int("-5")` = `-5` |
| `"-"` | `""` | 빈 글자라 탈락 → `None` |
| `"--5"` | `"-5"` | `-`가 숫자가 아니라 탈락 → `None` |
| `"+5"` | `"+5"` | `+`가 숫자가 아니라 탈락 → `None` |

앞의 `-`를 떼어 보는 건 검사용일 뿐, 마지막에 숫자로 바꿀 때는 원래 `text`를 써서 `-5`가 그대로 음수로 나옵니다.
